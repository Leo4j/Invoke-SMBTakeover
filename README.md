# Invoke-SMBTakeover

Unbind port 445/tcp on Windows

Powershell version of https://github.com/zyn3rgy/smbtakeover

## Usage

```
iex(new-object net.webclient).downloadstring('https://raw.githubusercontent.com/Leo4j/Invoke-SMBTakeover/refs/heads/main/Invoke-SMBTakeover.ps1')
```

```
Invoke-SMBTakeover -Action check
```

```
Invoke-SMBTakeover -Action stop
```

```
Invoke-SMBTakeover -Action start
```
